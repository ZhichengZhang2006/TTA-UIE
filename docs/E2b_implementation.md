# E2b 执行设置

沿用现有增强模型与 E1b 输出匹配规则，预算为 0.25、0.5、1、2 /255，主预算预先指定 0.5 与 1 /255。验收集从剩余 Utility Fit 按完整组固定取约 120 张，原 Risk Calibration 清单摘要用于封存核对。

SSPE 估计器先将输入缩小至 64×64，使用宽度 16/32/64 的 GN–SiLU CNN，再输出平滑的有界三通道 tD、tB 与全局 B。Shared 绑定两张透射图，Dual 分别预测。单网络参数少于 2M。Source Train 的参考只用于生成训练退化和监督，训练 60 epoch、batch 16、AdamW 2e−4，种子 2026/2027/2028。每个 batch 的图像顺序、生成随机种子、衰减和背景光均记录，噪声沿用 E2 的零噪声核心分布。开发清单为已消费 Pilot 图，checkpoint 仅按开发损失选择。

条件分支在开发阶段触发。任一 SSPE 的合成联合参数 MAE 低于 UDCP 的 95%，但 Shared/Dual 没有在主预算满足均值、危害率及相对 UDCP/自身融合/一致性方向的配对优势条件时，拟合有效参数并训练可部署预测器。有效参数采用 8×8 的 tD/tB 有界参数场和三通道全局 B，源域标签拟合 80 步，加入 UDCP 先验、TV 和背景先验约束。预测器访问 I 和固定 J0。残差精修器使用相同编码解码宽度，输出三通道有界残差，采用源域 L1+0.2(1−SSIM) 监督，以计算和容量相近的方式检查额外监督的贡献。

开发阶段另外以线性 RGB 标准差 0.005 与 0.01 的固定噪声检查参数预测敏感性，设置保存在独立 YAML 中。该检查不用于修改生成分布或选择验收图像。

自集成一致性由八种翻转旋转预测的反变换均值形成固定无标签目标。每个物理估计器各自提供一个匹配输出预算的解析反演融合对照。Oracle 梯度和标签拟合有效参数仅为源域诊断。

验收集仅在开发完成且权重摘要锁定后打开。每次候选都保留全部有限搜索尝试和静态回退状态。统计逐种子报告，并先在每张图内跨种子平均，再以去重组进行 5000 次重采样，避免把三种子的同一图当作独立样本。推进标准为预注册主预算上的均值 >0.05 dB、对 UDCP/自身融合的配对区间下界均 >0、有害比例 <15%，同时审阅非物理一致性对照和种子变异。
