# E0–E1 实现约定

| 问题 | 实现约定 |
|---|---|
| 资料路径 | 研究规范与原始 YAML 最初位于工作区根目录。`docs/PR_TTA_Research_Protocol_v1.md` 保存规范副本。`configs/v1.yaml` 是 E0–E1 的可执行配置，根目录 YAML 保留原始内容。 |
| 数据目录 | school-gpu2 的现有 LSUI 位于 `/home/user/UnderWaterDataset/LSUI`。三份原始目录用来定位配对文件，按源域规范重分组。样本 ID 包含原始子目录和配对文件名。 |
| 分组 | 对输入和参考交叉检查 SHA256。一般近重复需同时满足 pHash 汉明距离 ≤4 和 dHash ≤6。同数据集、同编号前缀的连续编号需同时满足 pHash ≤8 和 dHash ≤8。取连通组后按固定种子分配四个集合。数字文件名只在图像哈希也接近时提供证据。当前目录无可靠场景标注，哈希规则可能漏掉裁剪、视角变化或长间隔视频帧。 |
| 跨数据集检查 | 在现有 UIEB 和 EUVP-d/EUVP-s 配对文件上比较文件哈希和图像指纹。近重复记录供未来目标集去重审查。E0–E1 的训练、checkpoint 选择和审计只读取 LSUI。 |
| 输入和增强 | Pillow 转 RGB 后用双线性插值拉伸至 256×256，输入和参考使用相同变换。训练同步采用翻转和转置组合，覆盖 90° 旋转。按文件校验摘要、Pillow 版本和尺寸缓存变换后的 uint8 数据。 |
| Backbone | 编码器四级，各级两层 Conv–GN–SiLU，后三个编码级首层 stride 2。解码级从最深到最浅编号 1–3，在第 2、3 级 concat 后的 1×1 投影上加入 rank 4、alpha 4 的低秩分支。 |
| 训练与评分 | 按可执行 YAML 固定 2026 首轮种子和 200 个 epoch。研究规范列出的 2027、2028 可通过 `--seed` 运行。训练使用 BF16，L1 和 SSIM 的归约使用 FP32。SSIM 采用 11×11、σ=1.5 的有效区域高斯窗，逐图平均后裁到 [0,1]。PSNR 的 MSE 用 FP64 归约，设 1e−12 下限以避免完美配对出现无穷值。Tune 评分用 FP32 前向，严格按 PSNR 选 checkpoint，同分保留较早 epoch。 |
| UDCP 估计 | 使用规范的 sRGB 绿蓝暗通道、top 0.1% 中位数背景光和 5×5 透射率平滑。暗通道值并列时按像素索引排序。重投影在线性 RGB，置信掩码固定，均值低于 0.05 时跳过更新和 Probe。 |
| 梯度与步长 | 每个 Adapter 的 A、B 权重张量各作为一个块，非零块归一至单位 L2。单个物理假设的二次归一化等价于一次。采用 YAML 首轮默认步长 0.0003 和漂移上限 4/255，最多折半三次。首轮冻结参数，未用 E1 结果选步长。 |
| 确定性修正 | 首次 CUDA 独立重放出现最高约 3×10⁻⁷ 的候选输出差异。正式审计启用确定性算法和 `:4096:8` cuBLAS workspace，并将背景光中位数改为数学等价的稳定排序取下中位数。对原 checkpoint、原子集和原超参数重新审计。首张真实图像在全部其他图像之后再次执行，检查输出、评分和完整模型状态逐位一致。初次输出保留归档。 |
| 对照 | 五种条件都从同一静态参数开始。随机方向使用固定图像种子并与物理方向共享活跃块。错误透射率为裁剪后的 1−t，错误背景光取固定 Tune 子集中不同组的确定性供体。三种对照与物理更新共享归一化、步长和回溯规则，逐图记录实际更新 L2。 |
| 固定子集 | 对 Tune 图像 ID、实验种子和固定标签取 SHA256 排序，取前 200 张，记录各样本背景供体。完整 Tune 用于 checkpoint 选择，E1 子集用于机制分析。独立验证需使用从未参加 checkpoint 或候选超参数选择的源域样本。 |
| 审计统计 | 每图保存输出梯度余弦、各对照和 Probe 的 PSNR/SSIM、正负收益、有害阈值、最差 10% 均值和失败案例。候选未执行按静态计分，并保留状态。runtime_ms 是该图五种条件及 Probe 的审计总耗时，candidate_application_ms 是该条件的方向归一化和实际试步时间。 |
| 可追溯性 | 工作区未检测到 Git 仓库。运行记录保存 Git Commit 字段、Python 源码 SHA256、数据清单 SHA256、配置、随机种子、CUDA 和依赖版本。训练另保存训练代码摘要供断点恢复验证。 |
