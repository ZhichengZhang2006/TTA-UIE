# E1b–E2 固定实现

继承 v0.1 的 epoch 165 权重，SHA256 为 `479129a20eb1d8bc1a7b0d83ff7ce736e1b0d4152c17ed9be1b8101572bc2533`。2026 种子、六档输出预算、32 点有限对数步长网格和 10% 漂移容差均在 Pilot 前写入配置。参数位移上限取 Adapter 初态总 L2 的 25% 与绝对 0.5 的较小值。局部观测区间最多加密七次，满足容差即停止。无法匹配时返回静态输出，保留失败原因和最近漂移。

Utility Fit 按完整去重组取 40 张 Pilot、200 张 Fixed，剩余 410 张。已消费的 240 张单独登记。原始训练 manifest 保留用于核对 checkpoint，其分工由新诊断清单显式覆盖。Risk Calibration 清单只封存 ID 与已有元数据。诊断划分审核复用 v0.1 全部跨角色 SHA256、pHash/dHash 与序列阈值。

E2 对同一 Fixed 参考图生成 shared 和 dual 两种输入。每图使用相同深度、直接衰减和背景光种子，使配对模型比较控制生成因素。深度由 8×8 均匀随机网格双三次插值、裁剪至 [0,1] 后缩放到 [0.5,3]。三通道直接衰减分别在 [0.6,1.2]、[0.25,0.7]、[0.1,0.4] 均匀取值，背景光在线性 RGB 的 [0.15,0.6] 取值。dual 的后向散射衰减为直接衰减的 0.55 倍。核心实验噪声标准差固定为零，用于隔离模型与参数因素。

shared 含 true、estimated、错误 t、通道轮换 B，以及 t 和 B 分别按 ±10/20/40% 扰动，共 16 种。dual 含真实双衰减、仅 t 错误 20%、仅 B 错误 20%、简化模型加真实 tD/B、简化模型的系数最优拟合和简化估计模型，共 6 种。

“简化模型加最优匹配参数”在本实现中特指固定 t=tD、对空间恒定 B 最小化后向散射系数平方误差，得到 B_fit=B·sum[(1−tD)(1−tB)]/sum[(1−tD)²]，再裁到 [0,1]。它使用生成参数诊断模型表达能力，拟合过程不读取参考图。该约束解的最优性范围为固定 tD 的系数拟合。

所有可部署方向函数及漂移搜索函数均不接收 reference。Oracle 单独用 MSE 生成参数梯度。输出余弦来自各物理损失的输出梯度，参数余弦比较块归一化后的实际方向。Random/Fusion/Static 的物理输出梯度余弦留空。逐图 runtime_ms 含该方向梯度与共享六预算搜索，search_ms 单独记录搜索。六行预算共享搜索时间，汇总总成本时每图每方向计一次。

置信区间采用 5,000 次去重组重采样。全部预算、有效率、负收益、有害率、最差十分位和 Oracle Acceptance Gain 全量报告。配对表同时提供全部样本按静态回退的差值与双方均有效子集的差值。区间作为探索性描述，Go 判断同时审阅全部预注册预算。
